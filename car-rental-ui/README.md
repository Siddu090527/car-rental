# Car Rental UI

## Run locally

```powershell
cd d:\car-rental\car-rental-ui
npm install
npm start
```

Open the app at:

```text
http://localhost:4200
```

## Build

```powershell
npm run build
```

## Notes

- The frontend uses `src/environments/environment.ts` for local development.
- Production uses `src/environments/environment.prod.ts`.
- API requests are sent to `environment.apiUrl`.
